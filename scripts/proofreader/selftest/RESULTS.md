随机 200 条达到 <8% 目标；分层 200 条为 8.5%，**没有达到同一数值目标**。分层抽样增加了任务、多人与设备文本的比例，用于第 9.2 条覆盖检查，不能当作全量改动率估计。规格给出的通用 prompt 10–20% 是参考值，本次未另跑同样本通用 prompt 对照，不能据此断言因果改善。

两组均无中文音色退回英文、profile 变回配置文件；已逐项检查全部修订，未发现仅为润色的保留改动。原始模型确实提出过纯空格润色，最终由保护器拒绝：随机组 7375；分层组 32082、7375。并不声称模型本身从不犯错。

本次两组 sample 中未覆盖已锁定的 profile 纠正条目，profile 回退保护由离线回归直接验证。没有进行游戏画面或全量简繁识别，因此仍须按提案流程复核，不能直接落入人工锁定表。

## 程序验证

- `uv run python -m unittest scripts.proofreader.test_proofreader`：5 个行为测试通过（含多组 subTest/断言），涵盖数字占位符、重复/顺序、回退、路由、响应 id、确定性抽样、失败重试、候选拒绝和指纹失效。
- PowerShell 枚举 `scripts/proofreader/*.py` 后传给 `uv run python -m py_compile`：6 个 Python 文件编译通过。不能直接把未展开的 `*.py` 当作 Python 文件名。
- 两组真实任务均使用相同命令再次执行：直接从 worker part 恢复，计数与修订不变，无新增 batch 完成日志；两次续跑合计约 1.6 秒。
- `git diff --stat` 无已跟踪文件变更。此次只新增 `scripts/proofreader/`；原有未跟踪的 rule_scan 文件未处理。输入 SHA-256 记录于 `input_hashes.json`。

## 文件与复现

- `release_random200.json` / `release_stratified200.json`：每份包含全部输入译文，未抽到和跳过的条目保持原值。
- `release_*_changes.json`：模型提出并通过程序校验的修订，未做人工删改。
- `release_*.json.sample.json`：抽样英文、现译、id 与桶；用于完整复核每类至少 20 条。
- `release_*.json.report.json`：计数、拒绝记录和最终校验问题。
- `release_*.json.part.server-gpu*.json`：原始模型候选、理由与断点指纹。
- `development/`：实现调试过程的真实试跑，含已发现的坏提案，仅作审计，不代表最终交付版本。

命令见上级 README。当前代码仅输出修订提案；此次没有修改现有翻译数据，也没有写入 proofread_manual.json。
